### 2. **Softmax Activation Function**

#### Problems with Argmax:

- **Argmax** returns the index of the highest score, but its **gradient is zero**, making it useless for backpropagation.
    

#### What is Softmax?

- Softmax converts raw scores (logits) into probabilities.
    
- Ensures outputs are between 0 and 1 and that they **sum to 1**.
    

#### Why Softmax?

- Unlike **Sigmoid** or **ReLU**, **Softmax** is ideal for **multi-class classification** tasks.
    
- **Sigmoid** does not ensure outputs sum to 1.
    
- **ReLU** solves vanishing gradients but doesn't output probabilities.

🔗 [More on Softmax](https://www.singlestore.com/blog/a-guide-to-softmax-activation-function/)

### 5. **Mini-Batch Gradient Descent**

#### Problems with Stochastic Gradient Descent (SGD):

- **High variance updates**: Noisy updates cause the model to jump around.
    
- **Slow convergence near optimum**: Harder to settle at the minimum.
    
- **Inefficient hardware utilization**: Modern hardware is better utilized with batches.
    

#### Solution: **Mini-Batch Gradient Descent**

- Groups data into small batches and performs gradient descent on them.
    
- Balances the benefits of full batch gradient descent and SGD.
    
- Faster and more stable convergence.

### 6. **Dropout Regularization**

#### What is Dropout?

- Dropout is a powerful regularization technique to prevent overfitting in neural networks.
- During training, randomly "drop" (set to zero) a percentage of neurons in each layer.
- This forces the network to learn more robust features that don't depend on specific neurons.
- Think of it as training multiple smaller networks and then averaging their predictions.

#### How Dropout Works:

1. During **forward propagation**:
   - Randomly select a fraction of neurons to disable (set to zero)
   - Scale the remaining neurons' outputs to maintain the same expected output
   
2. During **backpropagation**:
   - Only update weights connected to "active" (not dropped) neurons
   - Use the same dropout mask from forward propagation
   
3. During **testing/inference**:
   - No neurons are dropped
   - No scaling is needed (since all neurons are active)

#### Key Implementation Details:

- Added a `dropout_keep_prob` parameter (probability of keeping a neuron active)
- Created random dropout masks during forward propagation:
  ```python
  D = np.random.rand(*A.shape) < keep_prob
  A = np.multiply(A, D)
  A = A / keep_prob  # Scale to maintain expected value
  ```
- Applied the same mask during backpropagation:
  ```python
  dA_prev = np.multiply(dA_prev, D) / keep_prob
  ```
- Disabled dropout during testing (is_training=False parameter)

#### Benefits of Dropout:

- Reduced overfitting and improved generalization
- Acts as an efficient form of "model averaging"
- Makes the network more robust by preventing co-adaptation of features
- Simple to implement with significant impact on performance

#### In Our Implementation:

- We added dropout with a keep probability of 0.8 (20% dropout rate)
- Applied dropout between hidden layers only (not on input or output layer)
- Ensured dropout is only active during training, not during evaluation or prediction

🔗 [Understanding Dropout](https://www.cs.toronto.edu/~hinton/absps/JMLRdropout.pdf)

### 7. **Adam Optimizer (Adaptive Moment Estimation)**

#### Problems with Standard Gradient Descent:

- Fixed learning rate requires manual tuning
- Slow convergence in complex landscapes
- Gets stuck in saddle points

#### Why Adam?

- Combines benefits of **Momentum** and **RMSprop**
- Adaptive learning rates for each parameter
- Faster convergence with less hyperparameter tuning

#### Key Features:

- Tracks exponentially decaying averages of gradients (`m`)
- Tracks squared gradients (`v`)
- Includes bias correction
- Default parameters work well (β₁=0.9, β₂=0.999)

🔗 [Original Adam Paper](https://arxiv.org/abs/1412.6980)
